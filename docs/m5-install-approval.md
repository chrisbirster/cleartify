# M5 slice 2 — published version install approval (no execution)

The user first calls `GET /api/protocols/{publicationID}/install-manifest` to see the immutable published version, requested permission strings, full specification SHA-256 and **manifest digest**. Then a **verified AT Protocol browser session** posts `{ "publicationId": "...", "acknowledgedManifestSha256": "..." }` to `POST /api/me/protocol-install-requests`. An exact acknowledgement of the latest manifest digest is mandatory; changed specifications and withdrawn/unpublished protocols fail closed. Published `spec_json` must contain explicit `permissions: []` (possibly empty). The request stores that version, manifest and acknowledgement immutably in a pending approval record.

An administrator may `POST /api/admin/protocol-install-requests/{id}/decision` with existing admin bearer and `{"approve":true|false}`. The decision is one-shot and rechecks the pinned spec hash. **Approval does not create an executable `protocol_installations` row**. Until ATProto social DID is securely linked to a phone-first Clear `users.id`, there is no safe owner mapping for the existing private installation table or approval-granted runner. Both approval and request responses explicitly return `installed:false, executed:false`. Existing M5 run requests remain separately admin-gated and have no execution path.

All endpoints are behind **`PROTOCOL_INSTALL_FLOW_ENABLED=true` AND `ATPROTO_OAUTH_ENABLED=true`**, both disabled by default. No production flag changes, network calls or payments are added. The 64-KiB max snapshot guards unexpectedly large specifications.

**Follow-up before executable installation:** reviewed DID↔Clear account linking, proof that permission manifests fully describe actual runner capabilities, mutable record prevention at publication, individual scope approvals, a consistent installation transaction, audit and revocation; owner sign-off for consequential permissions. This PR establishes explicit preview, user acknowledgement and administrative review only.
