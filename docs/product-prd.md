# Cleartify PRD

## Product
Cleartify is an AI-native product execution system.
It turns feedback, notes, prototypes, decisions, and code into working software.

## Core thesis
Tickets are not the source of truth.
Context is the source of truth.
Prototypes are the starting point of execution.
Agents handle procedural work.
Humans provide judgment, taste, and final review.

## Target user
Small, fast-moving product teams:
- founder-led startups
- product engineers
- design engineers
- internal platform/product teams

## MVP outcome
A user can:
1. connect product signal sources
2. view clustered product context in an inbox
3. convert a cluster into a work object
4. attach a prototype or notes
5. generate an implementation plan
6. generate execution artifacts
7. review and ship

## Core MVP features
1. Context Inbox
2. Work Object detail page
3. Prototype-to-Plan flow
4. Agent Workspace
5. Review / Release loop

## Non-goals for MVP
- full Jira replacement
- full document suite
- full IDE/editor
- full workflow automation platform
- enterprise compliance/admin complexity

## Product principles
- low ceremony
- context stays attached to work
- prototype-first
- code-aware
- human review before important execution
- clean, fast UI
