# M5 authenticated fake install-to-run integration

**DEFAULT (Oct 13 2026), owner can change.** `FAKE_INSTALL_RUN_ENABLED=false` by default and additionally requires private-alpha, Clear sessions and ATProto OAuth configuration to be enabled. No real executor, payment, deployment or external effect.

- `POST /api/me/fake-install-runs` accepts only an approved install-request ID, **not** caller-supplied Clear user IDs, social DIDs, plans or permissions. Private-alpha middleware checks live Clear identity and membership; the handler separately requires a live OAuth DID and an active DID-to-Clear link.
- The approved install request must belong to that DID, match the published protocol's pinned version and SHA-256 specification, and reference a non-private published creator publication. The service validates the declarative fake plan before making a one-time reservation; duplicate consumption is blocked by a unique install request constraint.
- A durable SQLite/Turso reservation and event are persisted **before** running the isolated in-memory fake simulator. Its bounded local.set/local.assert semantics have no network, filesystem, process or payment effects. Completion/failure and snapshot are recorded with another transaction and audit event. `GET /api/me/fake-install-runs/{id}` checks fresh Clear, alpha and link authorization and scopes results to the Clear user.
- Conservative fail-closed behavior: missing, expired, revoked or mismatched identities; missing alpha membership; changed approval/version/digest; unlisted/private access inconsistencies; and database/push failures deny access. A `reserved` run after a crash requires operator inspection; the code **does not** silently replay side effects or promise exactly-once execution across crashes.
- Real durable sandbox orchestration, transactional remote DB semantics under multi-instance concurrency, cancellation/recovery, consent/permission rechecks at time-of-run, cross-user security review, named audit actors and authentic hosted-PDS validation remain engineering and owner approval boundaries. This preview cannot be used to run real protocols.
