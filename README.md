# Cleartify

**Text Clear. It'll figure it out.**

Cleartify is being rebuilt from scratch as a text-first personal AI assistant.

The product direction is intentionally simple:

- **Text-first:** Clear should feel like a person in your contacts, not another app to manage.
- **Relationship:** persistent context, memory, follow-through, and proactive check-ins.
- **Execution:** Clear should keep working until an outcome is complete, not stop at an answer.
- **Protocols:** reusable, installable ways of getting things done.
- **Hidden agents:** models, tools, and specialist agents stay behind the scenes; the user talks to one assistant.
- **Trust:** Clear works for the user and asks for approval before consequential actions.

This repository is a fresh start. Previous implementation history remains available in Git.
